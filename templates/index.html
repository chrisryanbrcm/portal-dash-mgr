Step 1: Create the New Menu

            
    
              
  1. Log in to NetOps Portal as a user with administrative or designer rights.
    2. 
              
  2. In the top navigation bar, go to Administration > User Settings > Menus.
    3. 
              
  3. On the Manage Menus page, click New.
    4. 
              
  4. In the Add Menu dialog:
                
      
                  
    • Menu Name: Enter a display title for your custom menu.
      • 
                  
    • Description: Add an optional description.
      • 
                  
    • Add Dashboards: Select dashboards from the Available Dashboards list and click the Select item arrow to move them into the Selected Dashboards list.
      • 
                
    
              
    5. 
              
  5. Click Save.
    6. 
            

          

          

            
Step 2: Associate the Menu with User Roles (Required)

            
Important: Creating a menu does not automatically make it visible. You must assign the new menu to a User Role before users with that role can see it in their top navigation bar.

            
    
              
  1. Go to Administration > User Settings > Roles.
    2. 
              
  2. Select the target role (e.g., Network Administrator or a custom role) and click Edit.
    3. 
              
  3. In the Menus tab/section, locate your newly created menu in the available options.
    4. 
              
  4. Move the new menu to the Selected Menus column.
    5. 
              
  5. Click Save.
    6. 
            

            
Once saved, users belonging to that role will see the new menu and its assigned dashboards listed under the main Performance dropdown tab in the NetOps Portal header.

Before Using This File for Import

      

        Update the menu items to identify where this dashboard should exist in the new NetOps Portal menu hierarchy:
      

      
    
        
  • <dashboardMenu> (currently ): the top-level menu group the dashboard will be filed under.
    • 
        
  • <menuItem> (currently ): defines which menu group the dashboard will attach to.
    • 
        
  • <dashboardTitle> (currently ): the display name of the imported dashboard.
    • 
      

      

        If a dashboard with this exact <dashboardTitle> already exists on the target server, rename it in the XML before importing to avoid a name collision error.
